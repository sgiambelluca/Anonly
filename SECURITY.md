# Seguridad

Para informar una vulnerabilidad, usá [el reporte privado de GitHub](https://github.com/sgiambelluca/Anonly/security/advisories/new).

Describí la versión, el comportamiento observado y los pasos para reproducirlo con datos ficticios. No adjuntes expedientes, documentos clínicos, claves privadas ni información personal real. Si el caso requiere material sensible, acordaremos primero un modo de investigación adecuado.

La versión 0.9.x es preliminar. Los reportes se investigan sobre la versión preliminar más reciente; todavía no hay un compromiso de mantenimiento de versiones anteriores. Verificá el resultado de la anonimización antes de compartir un documento.

Los instaladores oficiales se publican en [GitHub Releases](https://github.com/sgiambelluca/Anonly/releases). Cada publicación incluye un archivo `SHA256SUMS.txt` para comprobar integridad. Las actualizaciones usan firmas específicas por plataforma; eso no convierte la aplicación en un producto certificado ni reemplaza la revisión del documento.
